# BIZNES.EXE 2.0

Lekka gra handlowa offline w klimacie retro DOS. Wybierz tryb **Dziecko**, kupuj tanio i sprzedawaj drożej przez 7 dni. Cel rundy: 1300 monet. Rekord i postęp zapisują się lokalnie. Tryby nastolatek, dorosły i zaawansowany są widoczne jako „wkrótce”. PL/EN, klawiatura, dotyk, wysoki kontrast, PWA. Bez konta, analityki i zależności runtime.

Uruchom `index.html` albo lokalny serwer HTTP. Testy: `node test-game.cjs` i `node test-classic.cjs`. Zasady i dalsze etapy: [strategia](docs/STRATEGIA-2.0.md), [plan](docs/PLAN.md). [Prywatność](privacy.html).

Wersja Classic pozostaje w katalogu [`classic/`](classic/) i pod adresem `/classic/`. Kod na licencji [Apache-2.0](LICENSE); informacje o czcionce w [NOTICE](NOTICE).
