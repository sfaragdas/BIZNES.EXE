# English Coach

A project area for an English-learning assistant that combines two goals:

- Help write in clear, natural English with a controlled, gradually expanding vocabulary.
- Teach vocabulary step by step, with examples and review.

The writing approach will use Simple English Wikipedia and plain-language guidance as references. Vocabulary learning will begin with a small, useful foundation and grow in stages. It will not require strict use of Ogden's Basic English 850-word system.

This public folder is for general project materials and reusable skill content. Personal vocabulary progress, notes, and preferences belong in a separate private repository or private storage.

## Planned structure

- `skill/` — reusable writing and teaching instructions.
- `curriculum/` — small, progressive vocabulary lessons.
- `docs/` — design notes and sources.

Vocabulary data will be added only with clear source and reuse information.
