# Small Words, Big Ideas

Start with a small, useful core of English words. Learn to use those words clearly and creatively, then grow the vocabulary step by step.

The project brings together two goals:

- Write clear, natural English using words from the learner's current stage.
- Build vocabulary gradually through short lessons, examples, and review.

Simple English Wikipedia is a reference for clear writing, not a strict word limit. Ogden's Basic English 850-word list is a historical starting point, not the whole course or a requirement to write only with 850 words.

This public folder is for general project materials and reusable skill content. Personal vocabulary progress, notes, and preferences belong in private storage.

## Planned structure

- `skill/` — reusable writing and teaching instructions.
- `curriculum/` — small, progressive vocabulary lessons.
- `docs/` — design notes and sources.

Vocabulary data will be added only with clear source and reuse information.
